# Generated school starter map

This is a rough Tiled-compatible starter map for testing only.

Assumptions:
- tileset uses a 64x64 grid
- source image: `public/assets/tilesets/generated-school/pencoedtre_generated_tileset.png`
- map file: `public/assets/maps/hub/pencoedtre_hub_starter.json`

Included layers:
- Ground
- Campus
- Props
- Collision (rectangles)
- Markers

Marker names:
- player_spawn
- pe_wing_door
- science_wing_door
- outdoor_fields_door
- hub_info_npc

This is intended as a quick bridge into Phaser/Codex testing, not a final authored Tiled map.
